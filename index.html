01 — Orchestrate

Distributed Job Queue & Worker System

NestJS monorepo (api/, workers/, shared/) with Docker Compose and Kubernetes (Kustomize / Minikube). REST APIs for job submit, batch enqueue, scheduling, status tracking, and attempt history.   • Workflow chaining, dependency graphs, failure propagation

  • JWT + role guards; 18+ Prometheus metrics; GHCR CI
  • Outputs via shared volumes or optional AWS S3
