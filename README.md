# Basanta Pokhrel — Portfolio

Light grayscale **Cryptical Coder / John Smith** style portfolio (Bedimcode-inspired React Smith layout), adapted for Basanta Pokhrel — Backend Developer.

## Preview

Open `index.html` in a browser, or:

```bash
cd portfolio
npx --yes serve .
```

## Sections

- Fixed floating bottom nav (Home, About, Skills, Services, Portfolio, Contact)
- Home with socials, animated blob profile, Download CV
- About, Skills accordion, Qualification tabs
- Services with modals, Portfolio filters, Testimonials, Contact form, Footer

## Stack

HTML · CSS · Vanilla JS · Boxicons · Poppins · assets from the Smith pack (`assets/`)
